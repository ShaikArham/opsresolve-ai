# OpsResolve AI

An interactive enterprise-support intelligence portfolio project by Shaik Arham Saquib.

The live demo lets visitors explore 200 fictional incidents, 26 troubleshooting procedures, SLA outcomes, ticket histories and an experimental triage analysis layer.

## Live site

After GitHub Pages is enabled, the project URL will be:

https://&lt;github-username&gt;.github.io/opsresolve-ai/

## Run locally

Open this repository with a local static web server. The site loads JSON files from the data folder, so opening index.html directly from a file browser may not load all features in some browsers.

## Project scope

All people, systems, support incidents and procedures are fictional. The included dataset was created for a portfolio demonstration. The experimental text classifier and procedure retrieval model are not production systems and the metrics do not establish production performance.

## GitHub Pages

In the GitHub repository, go to Settings, then Pages. Under Build and deployment, choose Deploy from a branch, then select main and /(root).
